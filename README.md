# Student Result Management System (C++)

## Overview
This C++ program is a simple **Student Result Management System**.  
It uses **Object-Oriented Programming (OOP)** concepts with a class named `Student`.

The program performs the following tasks:

- Calculates total marks using **recursion**
- Calculates percentage
- Assigns grade based on percentage
- Displays final result

---

## Concepts Used

- Class and Object
- Functions / Methods
- Recursion
- Arrays
- Conditional Statements (`if-else`)
- Return Values
